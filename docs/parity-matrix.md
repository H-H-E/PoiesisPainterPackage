# Pinned feature and parity matrix

**Issue:** [#2 source audit and licensing](https://github.com/H-H-E/PoiesisPainterPackage/issues/2). **Poiesis base:** [8665223329eedb138d90e81e1e8254fdc92cc99d](https://github.com/H-H-E/PoiesisPainterPackage/tree/8665223329eedb138d90e81e1e8254fdc92cc99d). **Audit:** 2026-11-15. Scope: source inspection only; no reference engine ran, no paired pixels visually judged, no parity benchmark measured. The project is an original v0.1.0 Canvas2D-CPU painting engine, **not** an assembly of the five source engines.

Every table row identifies a **particular** source implementation at its full locked commit, behavior/controls, evidence tier, Poiesis implementation and/or test, parity status and [reproducible probe](references/probes.md). The source-specific [audit pages](references/README.md) describe lifecycle, API, rendering/export, dependencies and licensing. The public [capabilities()](../src/painter.ts#L21-L30) is the conservative ground truth for Poiesis's advertised support.

## Status and evidence vocabulary

| Parity status (exactly one per row) | Meaning |
| --- | --- |
| **verified** | Paired source/Poiesis behavior executed and independently evidenced with sufficiently matching inputs; none of these audit rows qualifies yet |
| **implemented-unverified** | Same *kind* of feature exists in inspected Poiesis source, but comparator was not run |
| **approximate** | Inspected Poiesis implements a knowingly different/less comprehensive mechanism with related visible purpose; **not equivalent fidelity** |
| **missing** | A candidate public feature is not present in Poiesis score/API at the baseline |
| **unsupported** | A specific backend/capability is explicitly excluded in Poiesis `capabilities()` or required infrastructure is not supported |
| **inapplicable** | A source-specific workflow/benchmark is not a meaningful painting-core parity requirement |

Evidence tier **inspected** means pinned code was read; **upstream-reported** means source's benchmark/claim was read but not rerun; **not verified** means the Poiesis comparator has not been run. For every row below evidence is `inspected; parity not verified` unless `upstream-reported` is additionally noted. No rows are independently measured or visually reviewed. The presence of a Poiesis unit-test file is not proof that its assertions ran during this workstream.

## Cross-cutting constraints (do not collapse into generic parity)

| Question | Grounded decision |
| --- | --- |
| **Are strokes continuous?** | Poiesis samples Catmull–Rom input to connected Canvas2D geometry; p5.brush's GPU dots, sho's calligraphic bristles and oil-paint-agents's mobile reservoirs have different continuity rules. Validate PB02 / OA03 / SH01 separately. |
| **Does 'watercolor' mean paper physics?** | No. p5.brush shader fills are appearance-driven and dry at flush; washes-js & wet-edge have actual simulated water/pigment state; Poiesis has explicit conservative local transport. Never claim one is identical to another. |
| **Oil 'bristles'?** | Geometry resembling bristles is not per-bristle pigment/color transport; Poiesis holds one reservoir per stroke (within ordered chunks), unlike oil-paint-agents and sho. |
| **SVG export?** | Poiesis `capabilities().supports.svg === false`. Washes `traceSVG` **imports** SVG; oil-paint-agents `sketch.js` rasterizes an **input** SVG study. No source feature justifies claiming native editable SVG painting export. PNG is produced by Poiesis studio and Node harness from actual canvas pixels; JSON exports the score, not SVG. |
| **Timing and state?** | Poiesis `wait` = integer material simulation steps; sho point pauses and Washes timeline use wall-clock animation, p5.brush wet masks live for a flush, wet-edge persists physical paper stages. Match semantics before benchmarking. |
| **Compositing?** | Poiesis applies `normal/multiply/screen` across isolated layers; it does **not** transport pigment/water between layers. Reference wet paint physics often occurs on one sheet. |
| **Measured performance?** | None in this workstream. Source code provides [29 B per pixel](../src/materials.ts#L55-L58) for Poiesis's core fields plus optional 4 B cached RGBA, and additional canvases/caches; those are **allocation formulas**, not observed heap metrics. Upstream reported values stay labelled. |
| **Accessibility/compatibility?** | Poiesis Canvas2D and JSON editor operate without WebGPU; worker/GL additions need capability detection and a documented fallback. See [ADR](architecture.md). |
