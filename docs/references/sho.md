## Minimal reproduction — **specified only**

With locked checkout `../references/sho`, serve the repository locally (`python3 -m http.server 8765`) and open [examples/demo.html](https://github.com/enpts/sho/blob/ffcb4cafb28c710a2b32a21fcef8819d57854780/examples/demo.html). In a fresh page test the source [README quick start](https://github.com/enpts/sho/blob/ffcb4cafb28c710a2b32a21fcef8819d57854780/README.md#L13-L28): enqueue one JSON Lines stroke with pressure/angle/speed, then repeat one copy at speed 1 and one at speed 4, holding all else fixed. Use `flush()` or instant mode, export `engine.toDataURL()`, decode PNG and compare continuous ink, streak gaps and full width. Change `autoDip` between `false` and `'stroke'`, draw two consecutive strokes and inspect whether the second depletes. Place a `pause=1.5` at a control point to test pooling. Compare pale ink with bleed `capillary` versus `ring`. Feed JSONL in fragments through `StreamParser`, check that no incomplete line paints.

The corresponding Poiesis inputs are [studies()](../../examples/scenes.mjs#L90-L107), [samplePath](../../src/geometry.ts) and [MaterialSurface](../../src/materials.ts); see [probes.md](probes.md) IDs SH01–SH07. The tests should measure stroke width and sparse gap count at fixed size/seed and retain actual PNGs. A nice-looking ink mark is not evidence of calligraphic physics parity.

## Explicit exclusions

The exposed API does not export vector geometry/SVG; `toDataURL` encodes the final raster canvas. The optional paper image is not required for computation. `Sho.StreamParser` addresses incremental **input** parsing, whereas Poiesis `Painter.serialize` is complete JSON **output**. The capillary bleeding routine is a local image operation, not wetness conserved across the sheet or between strokes. None of these distinctions is resolved by a shared “ink” material label.
