## Example and concrete parity probes — **unexecuted**

The upstream [README example](https://github.com/halfprice06/oil-paint-agents/blob/09a2750b9fe1aa8c31b5741b1139ad1c0d72eef3/README.md#L35-L72) uses `p.stroke({points:[[40,120],[300,110],[560,130]], color:[['ultramarine',1],['titanium_white',4]], brush:'flat', size:70, load:1})` then a `load:0` filbert and `p.dry()`. Reproduce via `node .claude/skills/oil-painting/scripts/render.js examples/jug-and-two-apples --progress` then `--scale 3` at the pinned checkout, inspect `strokes.json`, pass PNGs, full image and crops.

The paired Poiesis study is [oil()](../../examples/scenes.mjs#L71-L88), with [oil overlap](../../examples/scenes.mjs#L104) and [tests/materials.test.mjs](../../tests/materials.test.mjs#L26-L44). See [probes.md](probes.md) for OA01–OA09.

The decisive minimal comparisons are:
1. **Reservoir:** draw a loaded dark stroke, then drag an empty brush from wet color into untouched space. Upstream should transfer picked-up color with individual bristle variation; Poiesis's one-reservoir chunk process may transfer color with less spatial structure. Inspect native 1x/3x pixels and tracked pigment mass; no claimed quantitative tolerance.
2. **Dry-vs-wet:** repeat the same second brush pass before/after `dry()`; expect different pickup upstream; Poiesis supports internal `surface.dry()`, but the public score lacks the command.
3. **Relief:** re-render the same score at 1x and 3x from input strokes; compare close-up groove profiles and highlight behavior, **not** nearest-neighbor upscaled PNG.
4. **Reproducibility:** same seed, engine and sequence → image bytes/hash repeat; change seed/stroke order → changes. No cross-repository hash equality is expected.

The examples' many-stroke imagery and counts in README are **upstream-reported examples**, not independent aesthetic judgments, and no upstream speed or output size has been measured here.
