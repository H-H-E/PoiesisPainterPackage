## Export, determinism and lifecycle

[Standalone render](https://github.com/acamposuribe/p5.brush/blob/054f2feb2ec8f98bd6dbb7d676d0335323180d83/docs/standalone.md#L72-L98) flushes WebGL2 operations to canvas. Consumers can then encode the canvas as PNG; this audit found **no first-party SVG command export** in [public exports](https://github.com/acamposuribe/p5.brush/blob/054f2feb2ec8f98bd6dbb7d676d0335323180d83/src/index.shared.js). [seed/noiseSeed](https://github.com/acamposuribe/p5.brush/blob/054f2feb2ec8f98bd6dbb7d676d0335323180d83/src/index.shared.js#L1-L15) set deterministic inputs, but pixel equality depends on GL backend/driver; no cross-device guarantee inferred. [docs/rendering.md](https://github.com/acamposuribe/p5.brush/blob/054f2feb2ec8f98bd6dbb7d676d0335323180d83/docs/rendering.md) calls explicit fill wetness **image-space** and does not implement water advection.

## Reproducible minimal checks — **specified, not executed**

Prerequisite: `npm run references` at the Poiesis root and a working WebGL2 Chromium browser. In `../references/p5.brush`, `npm install && npm test` exercises source behavior. For a minimal standalone comparator, [docs/standalone.md](https://github.com/acamposuribe/p5.brush/blob/054f2feb2ec8f98bd6dbb7d676d0335323180d83/docs/standalone.md) defines `createCanvas`, `set`, `line`, `fillBleed`, `render`; use the source's own `test/standalone/visual_suite.html` (serve via `npm run serve`). Capture same-seed brush line, image-tip, hatch polygon, flow field and consecutive washes. Probe PB01–PB10 using [probes.md](probes.md); record JS input, PNG, dimensions, browser/GPU and raw time. The source's `npm run measure:bench` data must be labelled independently gathered if rerun; its committed baseline files are **upstream-reported only**.

Specific parity criteria: (a) long path has no visually apparent gaps; (b) hatch segments remain inside concave polygon, density and line angle controllable; (c) bleed softness/coffee rim changes when fillBleed changes; (d) after `render()`, a subsequent fill does **not** mix with previously flushed wet fill; (e) custom tips and flow field respond to their respective inputs. For Poiesis, run `npm run check`, `npm run test:browser`, `npm run render` and inspect [material studies](../../examples/scenes.mjs). Similarity of a screenshot is not by itself a pixel-parity pass.

**Open discrepancy:** p5.brush's shader fill effects and persistent WebGL2 state are not the same as Poiesis's CPU transport or ribbons. No fidelity claim is justified without paired captures and a documented visual tolerance.
