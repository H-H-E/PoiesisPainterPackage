    06 / For makers & small agents

    A vocabulary,
    not a thousand APIs.

    An agent decides what to paint by writing bounded JSON, not executable code. Validate, repair, then render. Stable command IDs enable targeted edits.

    The examples use the source repository's public API and v1 score contract, and assume the package has been built or installed from this repository. npm publication is not asserted.

    Read the agent guide ↗
    PAINTER API / TYPESCRIPT
    import { Painter, validatePainting } from '@poiesis/painter';

const score = {
  version: '1.0', width: 320, height: 240, seed: 7,
  background: '#f3eee4',
  materials: { ink: { medium: 'ink', color: '#203847', size: 0.02 } },
  layers: [{ id: 'first', commands: [{
    id: 'gesture', op: 'stroke', material: 'ink',
    path: [[0.1, 0.8, 0.2], [0.5, 0.3, 1], [0.9, 0.6, 0.1]]
  }] }]
};
const result = validatePainting(score);
if (!result.valid) throw new Error(JSON.stringify(result.errors));
const canvas = document.querySelector('canvas')!;
const painter = new Painter(canvas);
await painter.render(score);
    AGENT INPUT / DATA ONLY
    Return exactly one JSON painting score, no Markdown or JavaScript.
Use schema version "1.0", width 320, height 240, seed 7.
Allowed media: ink, watercolor, oil, graphite, marker, knife.
Allowed commands: stroke, fill, hatch, family, wait.
Give every layer and command a unique stable ID.
Use #rrggbb colors and normalized x/y coordinates.
Start with an expressive, restrained two-color composition.
On a validation error, repair only the named JSON pointers.

    07 / A note on the medium

    The honest fine print.

    Experimental alpha. Poiesis currently uses CPU Canvas2D and bounded approximations of material behavior, not fully physical fluid simulation or professional painting software.

    There is no SVG export, spectral mixing, WebGPU acceleration, cross-layer wet transport, bitmap tips or Worker renderer. The playground sets stricter budgets than the schema to protect devices. Same-score output is repeatable on the same implementation and Canvas backend; browsers may differ.

    Rendering needs modern Canvas2D, structured cloning and PNG download support. The site runs entirely on the client, without accounts or paid AI APIs.
